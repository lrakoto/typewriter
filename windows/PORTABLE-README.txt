TYPEWRITER — WINDOWS 11 PORTABLE

Extract this ZIP into any folder you can write to, then double-click Typewriter.exe.
No installer, administrator permission, account, or separate .NET installation is needed.
The x64 build is intended for standard 64-bit Windows 11 PCs.

YOUR WRITING TRAVELS WITH THE FOLDER
Typewriter creates TypewriterData next to the EXE. Notes, preferences, recoverable
Trash, and the previous saved version of each file are kept there. Close Typewriter,
then move Typewriter.exe and TypewriterData together to move your writing. Back up
the entire TypewriterData folder. Replacing only Typewriter.exe updates the app.

Extract the ZIP first; do not run from inside the ZIP preview. Use a writable folder
such as Documents or a USB drive, rather than a protected folder like Program Files.
The bundled runtime may unpack native components into Windows' temporary cache
on first launch. Your notes and settings remain beside the EXE.

SHORTCUTS
Ctrl+N          New note
Ctrl+O          Import UTF-8 text or Markdown
Ctrl+S          Save now (also saves automatically as you type)
Ctrl+Shift+E    Export note
Ctrl+Shift+L    Show/hide library
Ctrl+F          Search the library
Ctrl+Z / Ctrl+Y Undo / redo
F11            Toggle full screen
Escape         Leave focus mode / close preferences / leave full screen

The top-right note menu contains import/export, Trash, Restore, and Open Notes
Folder. The bottom-right controls offer key sounds, spotlight, and preferences.

This first portable build is not code-signed. Windows may show a publisher or
SmartScreen notice when it is downloaded. No installer or elevated access is used.
